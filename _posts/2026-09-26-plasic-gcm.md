I am introducing **PlaSiC (Planet Simulator in C)**, a new general circulation model (GCM) that I developed to make climate-model development easier to learn and understand.

PlaSiC brings a coherent three-dimensional climate model into one approachable system. Its components include the atmospheric dynamical core, physical parameterizations, land, sea ice, a mixed-layer ocean, and a three-dimensional deep ocean. The project is written in C and is designed to keep the path from equations to source code visible.

The project also includes a detailed model guide, an annotated source tree, and a graphical interface for setting up experiments. Its historical experiment prescribes atmospheric CO₂ from 1850 to 2014 and reproduces the shape and scale of industrial-era warming in a coarse-resolution simulation.
